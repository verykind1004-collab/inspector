사용 가능한 XML Parameter 목록
ParameterDescription
SMS_DB encryptSMS 관련 주요 파라미터에 대한 암호화 적용 여부
- 기본: false (암호화 적용 후 true)
sms_database_typeSMS System의 DBMS 유형 (oracle / postgres / mssql)
sms_database_ipSMS System IP Address (기본: localhost)
sms_database_portSMS System의 DB port (기본: 1521)
sms_database_sidSMS System의 SID 또는 Service Name
service- 기본: false (SID로 접속)
- true 변경 시 Service Name으로 접속
- SID/Service Name 기본값: orcl
sms_database_userSMS System 접속용 DB user명 (기본: oracle)
sms_database_passwordSMS System 접속용 DB password (기본: oracle)
sms_database_query_timeoutSMS 발송을 위한 쿼리 수행 시 최대 응답 대기시간 (기본: 0)
bind_max_lengthSMS_SET_BIND_VALUE 내의 bind 값 각각의 최대 길이 (기본: 80)
RAC 관련 설정- racUse: RAC 여부 (기본: false)
- loadBalance (기본: false)
- failOver (기본: false)
- globalName (기본: "")
- Node (기본: 127.0.0.1:1521)
level설정한 알람 조건 이상일 때 SMS 발송
- 기본: N (N/W/C 설정 가능)
- N 설정 시 Normal Level 이상 알람 발생 시 호출
SMS_INSERT_QUERYSMS 정보를 입력하기 위한 INSERT 문장
- 파라미터는 "?"로 표시, SMS_SET_BIND_VALUE 참고
SMS_SET_BIND_VALUEINSERT 구문 내에서 사용할 bind 값을 제공
ParameterDescription
SMS_API encryptSMS API 관련 주요 파라미터에 대한 암호화 적용 여부
- 기본: false
- 암호화 적용 후: true
sms_methodRequest 방식을 입력한다.
- 기본: POST
sms_urlRequest 할 URL 주소를 입력한다.
- URL 주소 뒤에 ?를 입력한 뒤 파라미터를 입력할 수 있으며, 파라미터는 & 기호로 구분
- ex) http://[ip]:[port]/[page]?[p1]=[v1]&[p2]=[v2]
sms_msg_encodeRequest 할 때의 Encoding 타입을 설정한다.
- 기본: UTF-8
sms_tls_versionHTTPS 통신 시 사용할 TLS 버전정보를 설정한다.
- 기본: TLSv1.2
sms_timeout_conn연결 시간 제한을 위한 시간 값을 설정한다.
- 기본: 5
sms_timeout_read응답 시간 제한을 위한 시간 값을 설정한다.
- 기본: 5
sms_max_length파라미터 내 바인딩 값의 길이를 제한한다.
- 기본: 80
sms_headerh1: 요청 발신자의 인증 정보 (기본: Authorization:KEY)
h2: 전달할 content-type (기본: application/x-www-form-...)
h3: 리턴받을 content-type (기본: application/x-www-form-...)
h4: 파싱 시 사용할 Encoding (기본: accept-charset:utf-8)
level설정한 알람 조건 이상일 때 SMS API 호출
- 기본: N (N/W/C 설정 가능)
- N 설정 시 Normal Level 이상 알람 발생 시 호출
DATASMS API 호출 시 전달할 메시지를 설정한다.
- "%s", "%d" 등으로 표시하며 <PARAMETER> 섹션에서 제공
PARAMETERDATA 구문 내에서 사용할 bind 값을 제공한다.
ParameterDescription
SMTP encryptMail 관련 주요 파라미터에 대한 암호화 적용 여부
- 기본: false
- 암호화 적용 후: true
sslMail 발송을 위한 프로토콜 설정 (ssl 방식 발송 여부)
- 기본: true
auth검증된 사용자로 접근할 것인지 설정
- 기본: true
hostMail 발송을 위한 서버의 host 정보
- 기본: smtp.example.com
portMail 발송을 위한 서버의 포트정보
- 기본: 465
userMail 인증 및 발송을 위한 사용자 메일주소
- 기본: example@example.com
- Sender 파라미터가 있는 경우 auth 인증자로만 동작
senderMail 발송을 위한 사용자 메일주소
- 기본: exampleSender
passwordMail 발송을 위한 사용자 메일주소의 비밀번호
- 기본: example
headersMail 발송을 위한 smtp header 정보
- 기본: <header>name:value</header>
level설정한 알람 조건 이상일 때 Mail 발송
- 기본: N (설정 가능: N/W/C)
- N 설정 시 Normal 이상 알람 발생 시 메일 발송
SUBJECT알람 발생 시 발송되는 메일의 제목
CONTENT알람 발생 시 발송되는 메일의 본문
